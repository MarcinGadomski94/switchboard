### Audit
**Security (all pass):**
- **Bind:** `listenLoopback` refuses every host except `127.0.0.1` before opening a socket, then re-checks the bound address. At runtime the built app held exactly one listening socket, `127.0.0.1:4971`.
- **Guard on every route:** an in-process sweep over every registered route (all `/api/*`, `/hub`, `/hub/*`, unknown `/api/*`, HEAD variants) made 561 checks with 0 failures:
  - no cookie or a wrong cookie → `401`;
  - a foreign `Host` (`evil.example`, another loopback port, `0.0.0.0`, `[::1]`, a look-alike name) → `403 forbidden-host`;
  - a foreign `Origin` (another host, another port, `null`, `https:`) → `403 forbidden-origin`, even with a valid cookie.
- **Guard on the real process:** `/api/solutions` and `/hub` without a cookie → `401`; a foreign Host → `403`; `/hub` with a foreign Origin → `403`; `/hub` with the cookie → `200 text/event-stream`. The page issued `sb_token` as `HttpOnly; SameSite=Strict; Path=/` only on a browser load, and gave no cookie to a request without `Sec-Fetch-Site`. ## How to run
Requires Node ≥ 24 on PATH, plus `claude` (and `gh` for PR state) signed in for real sessions.

```sh
npm ci && npm run build && npm start
```

Then open http://127.0.0.1:4870 by typing it in the address bar. The page load sets the `sb_token` cookie; a page opened from another site gets none.

| Variable | Default | What |
|---|---|---|
| `SWITCHBOARD_PORT` | 4870 | Always bound on 127.0.0.1 |
| `SWITCHBOARD_DATA_DIR` | `~/Library/Application Support/Switchboard` (macOS) | Database + token |
| `SWITCHBOARD_CLAUDE_BIN` / `SWITCHBOARD_GH_BIN` | `claude` / `gh` | A command, or a JSON argv prefix |
| `SWITCHBOARD_DEMO` | off | `1` loads the prototype's demo data (needs a throwaway `SWITCHBOARD_DATA_DIR`) |

There is no workspace variable any more (D14, added after this report): add the folders sessions run in (the workspace, or single git repos) in the setup wizard or Settings → Folders, or through `POST /api/folders` (`docs/folders.md`). A root saved by the setup wizard before D14 is migrated as the default folder.

Start at login: Settings → Claude Code → "Start at login", or `npm run service:install -- --dry-run` to see the files first (`docs/service.md`). More detail is in `docs/configuration.md`.
